## Default-country resolution (account-wide, single owner)

The "First-domain default" column above is each recipe's DOCUMENTED default, not the final country. Every country-taking recipe resolves its actual `$COUNTRY` through this one inherited rule (do NOT reimplement it per recipe):

1. **User-stated country always wins.** If the user named a country, use it verbatim, even when the capability map says otherwise; the map never overrides explicit user input. (A user country the plan does not cover then surfaces the § Skip + pivot rule on the first call, as today.)
2. **Else, if the capability map has a readable `coverage` block** (present AND `coverage.observed_under` matches the live `tool_surface.hash`, per capability-map-schema § coverage read rule): use the recipe's documented default if it appears in `coverage.countries`; otherwise, if the covered set is effectively worldwide-only (no specific countries beyond `ww`/`world`), use `ww`.
3. **Else** (no map, stale/mismatched coverage, or a non-enumerable surface): use the recipe's documented default and let the § Skip + pivot rule fire on the country-coverage 400, exactly as before this rule existed.

This rule is account-wide because the country-coverage gate is: a requested-but-uncovered country returns the identical "No data for requested country" 400 across every country-taking family (grounded across traffic-and-engagement, keywords-seo-overview, traffic-channels, and pages on a worldwide-only account; see `country-coverage-gap-shape`). The four recipes whose documented default is `us` (sw-channel-mix, sw-page-mix, plus sw-keyword-opportunity and sw-aeo-audit via their us smokes) therefore default to `ww` on a worldwide-only account WITHOUT burning the sacrificial 400, while teardown and audience-overlap (already `ww`) are unaffected. Full-coverage accounts are unaffected: their covered set contains the documented default, so step 2 returns it unchanged. The partial-coverage branch (covered set names specific countries) follows the same step-2 test but is a documented inference pending an account that exhibits it; until then it degrades safely to step 3.

sw-router's dispatch prints the SAME resolved default (Branch A reads this rule), so the printed citation never disagrees with the country a recipe actually runs.
