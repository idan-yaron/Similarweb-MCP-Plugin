# codex/ (canonical Codex marketplace tree)

This directory is the source-of-truth Codex marketplace bundle for `similarweb` v0.1.2, committed to git so the Codex Desktop **Add marketplace** dialog can fetch it directly from this repository. Layout follows the Codex plugins spec at https://developers.openai.com/codex/plugins/build:

```
codex/
  .agents/plugins/marketplace.json     # Codex marketplace manifest
  plugins/similarweb/               # the plugin payload
    .codex-plugin/plugin.json          # plugin manifest with full interface block
    .mcp.json.template                 # MCP server shape (rename + fill in your key)
    assets/logo.png                    # Codex install-card icon
    hooks/                             # SessionStart, UserPromptSubmit, Stop
    skills/                            # per-skill SKILL.md + agents/openai.yaml
```

## Do not edit by hand

Files in this directory are auto-generated by `build.py emit_codex()` from the canonical sources at the repo root. Run `python3 build.py --build` from the repo root to regenerate. The same step produces `dist/similarweb-codex-<version>.zip` for the Releases page.

## How end users install via the Codex Desktop UI

1. Open Codex Desktop, click **Plugins** in the left sidebar.
2. Click the marketplace dropdown next to the search bar (defaults to "Built by OpenAI") and choose **+ Add more**.
3. In the **Add marketplace** dialog:
   - **Source**: `idan-yaron/Similarweb-MCP-Plugin`
   - **Git ref**: `v0.1.2` (or `main` for the latest)
   - **Sparse paths**: `codex`
4. Click **Add marketplace**. The marketplace registers and the plugin appears under the dropdown.
5. Open a new chat and type `compare nike.com and adidas.com on similarweb`.

See the [main README](../README.md) for the full install matrix across Cowork, Claude Code, Codex, and Cursor.
